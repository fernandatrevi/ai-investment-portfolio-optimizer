# Security and privacy

- The public dashboard does not ask for brokerage credentials, passwords, or personal account numbers.
- Do not commit API keys, tokens, .env files, or Streamlit secrets.
- Market prices are downloaded server-side from an external provider; availability is not guaranteed.
- The hypothetical capital input is used only for calculations and is not an instruction to invest.
- Dependencies should be reviewed and updated periodically.
- Do not represent this prototype as regulated investment advice.
