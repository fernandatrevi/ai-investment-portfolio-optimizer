# Public deployment checklist

1. Open https://share.streamlit.io/ and sign in with GitHub.
2. Select repository `fernandatrevi/ai-investment-portfolio-optimizer`.
3. Select branch `main`, main file `app.py`.
4. Deploy and wait for dependency installation.
5. Test stock selection, date validation, optimization and clustering.
6. Share the generated public app URL after verifying it opens in a private browser window.

Streamlit Community Cloud may sleep idle apps or impose resource limits. No brokerage account or secret key is required for this prototype.
